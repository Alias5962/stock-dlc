Stock & DLC / DDM

Tapez les chiffres : les « / » s’ajoutent seuls. Le bouton 📅 lit la date sur l’emballage avec l’appareil photo.

🔔 Notifications

Cochez quand vous voulez être prévenu avant la date de chaque produit. Exemple : « 7 jours avant » = une alerte une semaine avant la date.

Vérifier que ça marche

Si le test n’apparaît pas : Paramètres Android › Applications › Stock DLC › Notifications, puis Batterie › « Sans restriction ».

⏳ « Bientôt »

Un produit est « bientôt périmé » quand sa date est dans moins de ce nombre de jours.

💾 Enregistrement des données

Les données sont toujours enregistrées sur le téléphone. Vous pouvez en plus les sauvegarder sur Google Drive.

« Sauvegarder » ouvre le menu de partage : choisissez « Drive » ou « Enregistrer dans les fichiers ».
